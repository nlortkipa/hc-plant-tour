# ქარხნის ტური — თამაშის სცენარი

> წყარო: [`ქარხნის ტური_თამაშის სცენარი.docx`](./ქარხნის%20ტური_თამაშის%20სცენარი.docx)

## მიმოხილვა და მიზნები

ეს არის 2D გრაფიკული სასწავლო თამაში, სადაც თანამშრომელი  ვირტუალურად ივლის ცემენტის ქარხანაში, შეხვდება უბნების ხელმძღვანელებს, გაიცნობს წარმოების პროცესს და გაივლის შრომის უსაფრთხოების წესებს. თამაში იტვირთება ტალანტ LMS-ში SCORM პაკეტად.

**მიზნები:**

- გაციფრულებული ქარხნის ტური, რომელიც ფიზიკურ ვიზიტს ან ავსებს, ან ცვლის.

- შრომის უსაფრთხოების სტანდარტების (PPE, საშიში ზონები, წესები) შესწავლა თამაშის პროცესში.

- ქარხნის მთავარი უბნებისა და ცემენტის წარმოების ციკლის გაცნობა.

**სამიზნე აუდიტორია:** ჰანიველ ცემენტის ის თანამშრომლები რომლებიც სარგებლობენ ციფრული სასწავლო პლატფორმით

**ხანგრძლივობა:** 20-60 წთ

## ტექნიკური მოთხოვნები

თამაში უნდა აიგოს როგორც ბრაუზერში მომუშავე HTML5 აპლიკაცია და დაიპაკეტოს SCORM-ად LMS-ში ასატვირთად.

| **პარამეტრი** | **მოთხოვნა** |
|---|---|
| ფორმატი | 2D, გრაფიკული (sprite/ილუსტრაცია), ზემოდან-გვერდიდან (top-down ან side-scroll) ხედი |
| ტექნოლოგია | HTML5 + JavaScript (მაგ. Phaser, PixiJS, Construct 3 ან Articulate Storyline/Rise-ის გარეშე თავისუფალი კოდი) |

| პაკეტი | ერთი .zip, imsmanifest.xml ფესვში, ყველა რესურსი შიგნით, გარე სერვერებზე დამოკიდებულების გარეშე |

| ბრაუზერები | Chrome, Edge, Safari, Firefox (ბოლო ვერსიები) |
| ენა | ქართული ძირითადი; არქიტექტურა ისე, რომ ტექსტები ცალკე ფაილში იყოს (ინგლისურის დასამატებლად) |
| ხმა | **ფონური მუსიკა და ეფექტები ჩართვა/გამორთვით; ყველა დიალოგს ტექსტი აქვს** |
| პროგრესი | შენახვა LMS-ის suspend_data-ში, რომ მომხმარებელს გაგრძელება შეეძლოს |

## თამაშის ნაკადი და ლოკაციების რუკა

მოთამაშე გადის ქარხანას ცემენტის წარმოების ციკლის თანმიმდევრობით. ლოკაციებს შორის გადასვლა ხდება რუკაზე ან გზაზე სიარულით; თითოეული უბანი ცალკე 2D სცენაა. შემდეგი უბანი იხსნება წინა მისიის დასრულების შემდეგ.

- მთავარი შესასვლელი (KPP) და ეკიპირების არჩევა

- უსაფრთხოების მენეჯერთან შეხვედრა (ეკიპირების შემოწმება)

- ნედლეულის გადამამუშავებელი / დამსხვრევის უბანი

- ღუმელი

- CCR

- ცემენტის წისქვილი და სილოსები

- შეფუთვა და პალეტაიზერი

- დატვირთვა და ლოჯისტიკა

- ფინალური ტესტი და სერტიფიკატი

**მოძრაობა:** პერსონაჟი მოძრაობს ისრებით/WASD-ით ან შეხებით; ობიექტებთან მიახლოებისას გამოდის მინიშნება „დააჭირე E“ (ან შეხება).

**რუკა:** მენიუში ხელმისაწვდომია ქარხნის სქემატური რუკა, სადაც ჩანს გავლილი და დაბლოკილი უბნები.

შენიშვნა: უბნების ზუსტი ჩამონათვალი და თანმიმდევრობა უნდა დაკორექტირდეს თქვენი ქარხნის რეალური განლაგების მიხედვით.

## დასაწყისი: ეკიპირების არჩევა და უსაფრთხოების მენეჯერი

თამაში იწყება შესასვლელთან, გარდერობის სცენაში. მოთამაშეს ეძლევა პერსონაჟი (სურვილისამებრ სქესისა და გარეგნობის არჩევით) და ეკიპირების სია, საიდანაც უნდა აირჩიოს ქარხანაში შესასვლელად საჭირო ნივთები.

### ეკიპირების ნივთები(სწორი და არასწორი მიქსით): (ამას ზუსად შრომის უსაფრთხოება მოგვაწვდის თუ ჩავუშვებთ)

| **ნივთი** | **სტატუსი** |
|---|---|
| დამცავი ჩაფხუტი | სავალდებულო |
| დამცავი სათვალე | სავალდებულო |
| ყურსაცმები / ყურის ბუდეები | სავალდებულო (ხმაურიან უბნებზე) შესაბამის უბნებზე გამოვა არჩევანი რომ გაიკეთოს |
| მტვრისგან დამცავი რესპირატორი | სავალდებულო (მტვრიან უბნებზე) |
| მაღალხილვადობის ჟილეტი / სამუშაო ტანსაცმელი | სავალდებულო |
| დამცავი ფეხსაცმელი (ლითონის წვერით) | სავალდებულო |
| ხელთათმანები | სავალდებულო |
| ჩვეულებრივი ქუდი, სპორტული ფეხსაცმელი, სანდლები, შარფი | არასწორი არჩევანი |

**ლოგიკა:**

- მოთამაშე ირჩევს ეკიპირებას და დააჭერს „გაგრძელებას“; პერსონაჟზე ჩანს არჩეული ნივთები.

- კართან დახვდება უსაფრთხოების მენეჯერი (HS მენეჯერი) და ამოწმებს ეკიპირებას.

- **თუ ეკიპირება არასწორია ან არასრული:** მენეჯერი აძლევს შენიშვნას და დიალოგში ასახელებს, რა აკლია ან რა არის არასწორი და რატომ. მოთამაშე ბრუნდება გარდერობში და ირჩევს თავიდან. ყოველი შეცდომა ქულებში აისახება (შეცდომების რაოდენობა ინახება).

- **თუ ეკიპირება სწორია:** მენეჯერი მიესალმება, მოკლედ აცნობს ქარხნის ძირითად წესებს და უშვებს გზაზე.

**მაგალითი** არასწორის შემთხვევაში: „გამარჯობა! ქარხნის ტერიტორიაზე ამ ფეხსაცმლით ვერ შეხვალ. გთხოვ, დაბრუნდე და სწორი ეკიპირება აირჩიო.“

- სწორის შემთხვევაში: „გამარჯობა და მობრძანდი! ეკიპირება სრულყოფილადაა. გაიარე ქარხნის ტურზე და დაიცავი მარშრუტი.“

**ფიზიკური უსაფრთხოების წესები, რომლებიც აქ ისწავლება:** სავალდებულო PPE, ქვეით მოსიარულეთა მარშრუტი, აკრძალული ქმედებები (ტელეფონით საუბარი მოძრავ ტექნიკასთან, დაუშვებელი ზონები), სამუშაო ადგილის ევაკუაციის სიგნალები.

## უბნები, მენეჯერები და მინი-მისიები

თითოეულ უბანზე შესვლისას მოთამაშეს ხვდება ამ უბნის ხელმძღვანელი (NPC). შეხვედრა მოიცავს სამ ნაწილს: (1) უბნის და პროცესის მოკლე ახსნა დიალოგით/ანიმაციით, (2) უსაფრთხოების წესი, რომელიც ამ უბანს ეხება, (3) მინი-მისია ან კითხვა გასაგრძელებლად.

| **უბანი** | **NPC** | **პროცესი(რას ისწავლის)** | **უსაფრთხოების თემა** | **მინი-მისია** |
|---|---|---|---|---|
| გარდერობი / KPP | უსაფრთხოების მენეჯერი | შესვლის წესები | სრული PPE | ეკიპირების სწორად არჩევა |
| დამსხვრევა | დამსხვრევის უბნის უფროსი | კირქვის დამსხვრევა, ტრანსპორტირება | ხმაური, მძიმე ტექნიკა, ტრანსპორტის მარშრუტი | სწორი ქვეითი გზის პოვნა მძიმე ტექნიკისგან თავის არიდებით |
| ნედლეულის წისქვილი | წისქვილის უბნის უფროსი | ნედლეულის დაფქვა და შერევა | მტვერი, მოძრავი მექანიზმები | მოძრავი ნაწილების ზონის ამოცნობა |
| CCR | CCR-ის უფროსი | პროცესის ავტომატური მართვა, მონიტორინგი | გადაუდებელი სიტუაციების სიგნალები, ევაკუაცია | მარტივი სიმულაცია: ეკრანზე გაფრთხილების სიგნალზე სწორი რეაქცია |
| ცემენტის წისქვილი | ცემენტის წისქვილის უბნის უფროსი | კლინკერის დაფქვა, დანამატები, მარკები | დახურული სივრცეები, მტვერი | სწორი ნიშნების შეჯერება მარკებთან |
| სილოსები | სილოსების/ტერმინალის უფროსი | შენახვა და გადატვირთვა | სიმაღლეზე მუშაობა, დახურული სივრცე | აკრძალული მოქმედებების აღმოჩენა სცენაში |
| შეფუთვა და პალეტაიზერი | პალეტების უბნის ხელმძღვანელი | ცემენტის ტომრებში ჩატვირთვა, პალეტიზაცია | ავტომატური რობოტული ზონები, ამწეები | სწორი პალეტის დასაწყობება და უსაფრთხო მანძილი |
| ლოჯისტიკა | ლოჯისტიკის მენეჯერი | დატვირთვა, ავტოტრანსპორტი | მოძრავი ტრანსპორტი, ტვირთის დაგებება | ტვირთის უსაფრთხოდ დატვირთვა |

**საერთო მექანიკა:** უბნის უფროსი თავდაპირველად იძლევა სიტუაციის აღწერას; ყოველი სწორი პასუხისთვის მოთამაშე იღებს ქულებს და ხსნის შემდეგ უბანს.

**უსაფრთხოების გადაწყვეტილებები:** ზოგიერთ უბანზე მოთამაშეს თავად უწევს გადაწყვეტილება, მაგალითად „სად გავიარო“, „ვინ ახლოსაა“, „რა გავაკეთო სიგნალის გაჟღერებისას“. არასწორი არჩევანი გამოიწვევს შენიშვნას უბნის უფროსისა ან უსაფრთხოების მენეჯერისგან და ქულის შემცირებას.

**ფაქტების ბარათები:** თითოეულ უბანზე 2–3 ინტერაქტიული ობიექტი (მაგ. დანადგარი, ტაბლო), რომელზე დაჭერითაც ჩნდება მოკლე ინფო ან ციფრული ფაქტი.

## ქულები, შედეგი, SCORM მონაცემები

თამაში ითვლის ქულებს უსაფრთხოების გადაწყვეტილებებზე და ცოდნის შეკითხვებზე, ბოლოს კი LMS-ს გადასცემს სტატუსს და ქულას.

**ქულების სისტემა(წინასწარი, დასაზუსტებელი):**

- ეკიპირების სწორი არჩევა პირველივე ცდაზე: მაქსიმალური ქულა; ყოველი შეცდომა აკლებს ქულას.

- თითო უბნის მინი-მისია და კითხვა: ქულები სწორი პასუხისთვის.

- ფინალური ტესტი: 10 შეკითხვა წარმოებასა და უსაფრთხოებაზე.

- გავლის ზღვარი: მაგ. 80%

- ფინალში მოთამაშეს ეძლევა სერტიფიკატი/ბეჯი

## გრაფიკული სტილი და ინტერფეისი

**სტილი:** სუფთა 2D ილუსტრაცია (flat/ვექტორული ან პიქსელ-არტი), კორპორატიული ფერებით, ქარხნის ბუნებრივი ატმოსფეროთი. გრაფიკა უნდა ჰგავდეს რეალურ უბნებს, რომ ადამიანმა ფიზიკურად შესვლისას ამოიცნოს.

**პერსონაჟები:**

- მოთამაშის ავატარი: 2–4 ვარიანტი, ეკიპირება ჩანს პერსონაჟზე.

- მენეჯერები: ცალ-ცალკე უნიკალური ილუსტრაცია, პორტრეტი დიალოგში და სახელის/თანამდებობის წარწერა.

**ინტერფეისი:**

- ზედა პანელი: პროგრესის ზოლი, ქულა, რუკის ღილაკი.

- ქვემოთ დიალოგის ფანჯარა (პორტრეტი, ტექსტი, არჩევანის ღილაკები).

- ინვენტარი/ეკიპირების პანელი.

- ხმის და სუბტიტრების პარამეტრები.

- „დახმარება“ ღილაკი მართვის ინსტრუქციით.

**ბრენდინგი:** კომპანიის ლოგო და ფერები უნდა შეთანხმდეს კომუნიკაციების გუნდთან; გამოსაყენებელი ფოტოები/ლოგოები უნდა მოწოდდეს ბრენდ-გაიდის მიხედვით.

**ხელმისაწვდომობა:** ტექსტის მკაფიო ზომა და კონტრასტი, ყველა დიალოგს ტექსტური ვერსია აქვს, ინტერაქციები შესაძლებელია კლავიატურითაც.
